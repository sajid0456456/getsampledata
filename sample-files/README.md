# sample-files/

Real downloadable sample files live here, one subfolder per category once
you add categories through the Manager, and one further subfolder per
format inside each: `sample-files/<category>/<format-code>-sample-files/`.

This is currently empty — the site is starting from scratch with no
categories or files uploaded yet. Uploading through the Manager's Files
tab creates these subfolders and saves files here automatically; you don't
need to create anything here by hand.
